# 低频维护任务

本文件用于改名迁移、旧名残留检查、结构检查等低频维护。普通润色、句式调整、段落增删不读取本文件。

## 旧名残留检查

`references/name-map.md` 是历史旧名 -> 新名的迁移表，不是日常命名规范库。

只有以下情况使用：

- 大规模改名
- 统一角色称呼、地名、术语
- 批量替换名称
- 用户明确要求检查旧名残留

命令：

```bash
python scripts/check-names.py --work <work-id>
```

有 FAIL 必须修复后重跑至 PASS。普通正文润色不跑。

## 结构检查

项目结构完整性偶尔检查，或用户明确要求时运行：

```bash
python scripts/check-structure.py
```

## 维护原则

- 低频工具不写进主写作流程。
- 旧名表只记录已经废弃、需要清理的历史名称。
- 新的角色称呼体系或命名风格，不塞进 `name-map.md`；需要时另建命名规范引用。
