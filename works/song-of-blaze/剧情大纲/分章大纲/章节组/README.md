# 章节组细纲

这里存放《炽炎的颂歌》接下来一组连续章节的短期执行计划。

章节组由情节单元决定，不按固定章数硬切。它承接长期大纲和已写正文，服务接下来几章落笔，不替代总纲、分幕大纲、角色卡或正式设定。

## Current

- 当前待规划单元：第一幕“根域相遇”中第三章及其后续承接。
- 推进第三章前，先读 `正文草稿/章节/chapter-3-README.md`，再决定是否新建 `group01-*.md`。

## File Format

```markdown
# groupXX：短期情节目标

## 章节组目标

## 承接状态
- 当前进度：
- 主角状态：
- 关键角色状态：
- 未解决钩子：

## 覆盖范围
- 建议章节：
- 预计章数：

## 组内冲突曲线
1. 起点：
2. 升级：
3. 转折：
4. 落点：

## 逐章安排

## 伏笔与回收

## 待确认点
```

## Rules

- 只规划接下来一组章节，不一次性批量展开多组。
- 正文已经偏离旧大纲时，先标出偏差，再决定改大纲还是让章节组拉回主线。
- 已完成章节摘要写入 `项目管理/创作进度/README.md`，不要写回长期大纲。
