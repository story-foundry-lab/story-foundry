# 露维的部族——树叉聚落

> 露维故事的起点。一个不算苦但也不富裕的地方，大人每天为吃的发愁，但小孩还是能玩能闹。

---

## 基本信息

| 项 | 内容 |
|---|---|
| 位置 | 安姆主干中段一处大分叉的内侧，不属于根域也不属于冠域 |
| 地形 | 分叉处形成天然的"碗"状凹地，两根巨枝夹出的空间。底部有碎石和薄土层，四周是树皮壁和藤蔓网 |
| 规模 | 约 120–150 人 |
| 光照 | 有微弱的漫射光从上方叶雾透下来——永远的黄昏感。不是全黑，但也远不到明亮 |
| 气候 | 温暖潮湿。树干内部的树液循环带来余热，分叉处风小，叶雾凝结成露水 |

### 与根域、冠域的区别

| | 根域 | 露维的部族 | 冠域 |
|---|---|---|---|
| 光 | 极度稀缺，光是货币 | 有一些漫射光，不够亮但不至于全黑 | 充足，花光 |
| 泥土 | 无 | 少量——分叉处卡着的地壳碎片 | 厚土台地 |
| 核心稀缺 | 光 | **食物**（什么都有一点但什么都不够多） | 泥土 |
| 危险 | 暗季猎手常态出没 | 有敌对生物，偶尔危险但不是日常恐惧 | 安全 |
| 火 | 绝对禁忌 | 也是禁忌——会烧伤安姆的树干组织 | 教会垄断 |
| 文明程度 | 小部族，口述传统 | 小部族，口述传统 | 王国，有文字 |
| 对外界 | 不知道上面有什么 | 模糊知道上面和下面都有"别人"，但没怎么接触过 | 不知道下面有人 |

## 食物

部族的核心问题：**能活，但活得单调。**

| 食物 | 来源 | 味道/口感 | 获取难度 |
|---|---|---|---|
| **菌类**（主食） | 树皮裂缝、藤蔓根部大量生长 | 品种多，口感从面到脆都有，但味道寡淡 | 低。最容易获取，采集队日常工作 |
| **苔薯** | 薄土层上种植 | 介于木头和面糊之间，管饱不好吃 | 低，但产量受限于土的面积 |
| **树髓浆** | 刮取枝干内壁的软质层 | 微甜，黏糊糊的，碳水来源 | 中。不能刮太深伤到安姆 |
| **虫类** | 各种树栖节肢动物 | 蛋白质来源 | 中。需要猎捕，有些虫有攻击性 |
| **灌木浆果** | 分叉处灌木丛偶尔结的小果子 | 酸涩，勉强能吃 | 低，但量很少 |
| **藤甜瓜**（稀有） | 长在须根与主干交汇的特定节点上 | **甘甜多汁**，公认最好吃的东西 | **高** |

### 藤甜瓜

- 长在须根和主干交汇的节点处，那些地方树液营养最丰富
- 外皮暗绿色，和树皮颜色接近，不仔细看很容易错过
- 成熟的甜瓜大概小孩拳头大小，掰开里面淡黄色果肉，汁水很多
- 成熟周期很长，不是每个节点每次都会结——有时候一个节点好几个旱季才出一颗
- 部族会标记已知的甜瓜节点，但位置散布在活动范围各处，有些在比较偏远或不好爬的地方
- 找到一颗成熟的甜瓜值得高兴，通常带回来大家分着吃
- **露维是部族里最擅长找甜瓜的人之一**——她记住了很多节点的位置，而且敢爬到刁钻的地方去

## 生态——动物

### 敌对/危险

| 生物 | 外形 | 习性 | 威胁等级 |
|---|---|---|---|
| **刺背蜈** | 成人手臂长的多足节肢动物，背上一排硬刺，体色和树皮几乎一样 | 领地意识极强，藏在树皮裂缝里，被打扰会弹射出刺。刺尖有麻痹毒素 | **中**。不主动攻击，但采集时经常不小心碰到。被刺中后半边身子发麻几个时辰 |
| **雾蛾** | 巴掌大的蛾类，翅膀半透明，飞行几乎无声 | 被光吸引，大群涌向光源。本身无害，但大群遮蔽视线，还会吸引更大的捕食者 | **低**。主要是烦人 |
| **钩爪猴** | 比猫略大的树栖哺乳类，四肢末端有弯曲硬爪。杂食，群居 | 通常避开人类，但饥饿时会偷食物——尤其是甜瓜和浆果。成群时胆子很大 | **中低**。小孩单独遇到一群会比较危险，大人通常能赶走。和部族的关系是"互相嫌弃但凑合共存" |
| **裂口蟾** | 脸盆大小的两栖类，皮肤湿滑，藏在积水坑里 | 伏击型猎手，突然张嘴吞食经过的小动物。偶尔咬到人的手脚 | **中低**。不致命但咬合力很强。小孩从小被教育不要把手伸进积水坑 |
| **深层游荡者**（传说级） | 没有人真正见过完整的样子。偶尔在分叉下方的深层雾中出现巨大的影子，或听到低频震动声 | 不明。可能是从根域上来的大型捕食者，也可能是安姆自身组织的大规模运动 | **高但极罕见**。大人用来吓小孩："别往下面爬，游荡者会把你拖走。"露维半信半疑 |

### 友好/中性

| 生物 | 外形 | 和部族的关系 |
|---|---|---|
| **叶缕虫** | 小指长的发光软体虫，身体像透明丝带，发出极微弱青白冷光 | 部族的"宠物"级存在。小孩喜欢抓来玩，放在手心看它发光。无害，捏一下会缩成一团 |
| **藤雀** | 拇指大小的飞行生物（更像飞行甲虫），翅膀振动频率高，发出嗡嗡声 | 给灌木授粉的关键物种。"藤雀多的地方，灌木就长得好。"不怕人，经常停在人身上 |
| **树脂螺** | 指甲盖大小的螺类，背着半透明螺壳，壳里有时积一小滴树液 | 小孩收集壳当玩具——举起来对着光看，像微缩琥珀。偶尔从壳里嗦出一口甜甜的树液 |
| **鼓腹蛙** | 比拳头小的蛙类，肚皮鼓起来可发出不同音调叫声 | 长暗期集体叫，是部族夜里的"背景音乐"。叫声越密说明湿度越高。大人靠它们判断天气 |

## 日常节奏

| 时段 | 活动 |
|---|---|
| 漫射光最亮时（"亮时"） | 全部户外活动——采集、修补藤桥和屋子、晾晒菌类。小孩在外面疯跑 |
| 漫射光变暗（"暗时"） | 收回聚落。吃饭（菌子和苔薯为主，生食或热泉泡软）。大人做藤编、修工具 |

## 备注

- 这个部族可能不是树干上唯一的聚落——类似位置可能还有其他部族，但目前先专注写这一个
- 部族对冠域和根域有模糊认知：知道上面更亮、下面更暗、都有"别人"，但没有实际接触
- 食物是核心矛盾——不至于饿死，但"吃腻了菌子和苔薯"是日常情绪，甜瓜这种好东西才格外珍贵

## 繁衍方式——树生人

树藤世界的人类从安姆的特定节点中"长出来"。

### 机制
- 安姆的某些树瘤/果实结构中，偶尔会孕育出人类婴儿
- 频率很低，可能几个旱季才出现一个
- 婴儿从树瘤里剥出来时是完整的，像一颗果实熟透了
- 部族定期巡查已知的"孕节点"，发现婴儿就带回来由全族共同抚养

### 社会影响
- **没有亲生父母的概念**。每个孩子都是安姆给的，由部族共同养大
- **首养人制度**：每个婴儿带回来后，会有一个成年人自愿主要负责照看——"首养人"。不是父母，更像师傅 + 主要照看者。一个人可以是多个孩子的首养人。孩子长到七八岁能自理后，关系自然松一些，但亲近感留下
- **没有血缘意义上的亲疏远近**。部族里所有人的来源一样，关系区别只在于日常互动的亲密程度
- **出生疤**：每个人被剥出来的孕节点上会留下一个疤痕。部族里的人知道彼此的出生疤在哪——那是和安姆之间最私人的联系

### 凝聚力来源

没有血缘，部族靠四样东西凝聚：

1. **功能绑定**——每个人都是别人活下去的条件。莫砾管光，塔玛婶管苔薯，阿岩放哨，采集者找吃的。少了任何一环，全族都受影响。不是抽象的互助精神，是"今天你不采菌子，明天全族少吃一顿"
2. **共同来源的身份认同**——"我们都是安姆长出来的"。所有人起点一样，没有先天的亲疏差异
3. **首养人纽带**——最接近"亲"的关系，给每个人至少一个特别亲近的情感锚点
4. **达恩的歌（集体记忆）**——歌谣是全族共享的历史。你听着这些歌长大，你就是这个部族的人

## 繁衍设定对露维价值观的影响

### 她天然觉得"照顾不认识的人"是正常的
她自己就是被不认识的人养大的。一个孩子哭了，附近大人就会管。她不觉得帮助陌生人需要特别的勇气——对她来说那是日常。

**→ 影响对天泽的态度**：一个不会说话的奇怪存在出现了，她的第一反应不是"这是谁"，而是"她好像不太行，要不要管一下"。不是英雄行为，是习惯。

### 她不理解"排斥外来者"
部族里每个人都是从孕节点"捡"回来的——某种意义上每个人都是外来者。当部族要驱逐天泽时，露维会困惑：**我们不也是被捡回来的吗？为什么她不行？** 不是成熟的道德判断，是小孩基于自身经验的朴素逻辑。

### 她对"归属"的理解是具体的、行为性的
归属感来自具体的事：和安洁丽雅一起住的藤屋、塔玛婶教她浇苔薯、达恩的歌里她能哼出每一句。后面离开部族时，她舍不得的不是抽象的"家"，而是这些日常碎片。

### 她没有"继承"的概念
没有血脉就没有"你该怎样"的家族期望。她是彻底自由的个体——13 岁时表现为"想干嘛干嘛，大人管不住"，成长后表现为"我的选择只代表我自己"。

和天泽形成镜像——她们都是"没有根的人"，只不过露维在一个给了她归属感的部族里长大，天泽连这个都没有。
