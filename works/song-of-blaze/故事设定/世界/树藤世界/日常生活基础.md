# 树藤世界·日常生活的物质基础

> 世界观的可信度不在于宏大叙事，而在于角色吃什么、喝什么、怎么点灯。

---

## 一、食物

### 根域（无土、无光、无火）

| 食材 | 来源 | 说明 |
| --- | --- | --- |
| 菌类 | 须根表面和树皮裂缝中大量生长 | 主食。品种繁多，从面包质地到肉质口感都有 |
| 树髓浆 | 刮取须根外层的软质层 | 类似薯泥的碳水来源，味道温和 |
| 虫蛋白 | 树脉附近活动的大型节肢类 | 重要蛋白质来源。狩猎有风险但回报高 |
| 树液 | 从须根裂口处收集 | 甜味液体，可直接饮用或发酵酿造 |

**根域没有任何"种植"的概念**——他们没见过泥土，不知道种子可以发芽。所有食物都是采集和狩猎所得。

### 冠域（有土、有光、限火）

| 食材 | 来源 | 说明 |
| --- | --- | --- |
| 谷物/根茎 | 泥土台地上的农田 | 主食。但耕地面积极有限——每一寸土都精心维护 |
| 树果 | 安姆枝条上结出的果实 | 季节性食物，花雨季最丰 |
| 菌类（养殖） | 树皮裂缝中人工培植 | 补充食物——冠域也种菌，但不像根域那样依赖 |
| 肉类 | 驯养的小型树栖动物 | 数量有限，肉食不是日常 |

**冠域的农业困境**：泥土不可再生，长期耕种导致肥力下降。轮作、休耕、堆肥（用树叶和动物粪便）是维持产出的关键——但终究是在消耗一个有限的总量。

## 二、水源

树藤世界没有海洋和自然降雨，所有水来自安姆的循环系统：

| 层域 | 水源形式 | 说明 |
| --- | --- | --- |
| 根域 | 树液泉 + 岩缝渗水 | 树液泉是部族选址的首要条件；水中矿物含量高 |
| 冠域 | 叶面露水 + 叶雾冷凝 | 冠域温差大，巨型叶片上的露水汇聚成溪流 |

## 三、照明

### 根域：光即生命（详见垂直社会分层·光的生态）

| 光源 | 特性 |
| --- | --- |
| 冷光菌落 | 基础照明，微弱但稳定 |
| 萤瓶 | 便携光源，也是货币 |
| 荧石 | 高价值储能光源 |
| 脉光潮 | 唯一的"白天"，持续数小时 |

**所有光源都是冷光。** 根域居民对"热的光"没有概念。

### 冠域：光是理所当然的

- 花光（花开为昼，花合为夜）
- 荧光补充（花合后树脉微光）
- 人造光：树液灯（树液密封在树脂容器中自然发光）

冠域不缺光，但**缺火**——教会垄断用火权。

## 四、火与热

这是树藤世界最核心的物质设定之一：

### 安姆与火的关系

安姆厌恶火焰。这不是迷信——火焰确实会灼伤安姆的活体组织。在树皮表面点火，周围的树脉会收缩、荧光会熄灭、树液会停止流动。大规模用火可能引发树体局部坏死，甚至触发安姆的免疫反应（自剪该区域的枝条）。

### 根域：绝对禁火

- 火光在黑暗中极其醒目——会在数公里外被暗季猎手感知
- 火的温度会扰乱冷光菌落——可能导致部族赖以生存的菌落死亡
- 根域居民对火有本能的恐惧，不是宗教灌输，而是生存经验

### 冠域：教会垄断的"圣火"

- 教会宣称只有经过祈福仪式的"圣火"才不会触怒安姆
- 实际上：教会掌握了在安姆组织上安全用火的方法（可能是特定的隔热材料或特殊位置）
- "圣火"的实际用途：冶炼铁器、特殊烹饪、宗教仪式
- 普通居民无权用火——冠域的日常烹饪同样依赖无火方式

### 无火的烹饪与取暖

| 方式 | 原理 | 使用层域 |
| --- | --- | --- |
| 生食 | 菌类、树髓浆、风干虫肉直接食用 | 根域为主 |
| 热泉烹饪 | 利用树脉热量或地核余热的热泉 | 根域 |
| 树脂热石 | 特殊树脂与矿物接触时放热（化学反应，非明火） | 所有层域 |
| 发酵 | 大量食物通过发酵加工 | 所有层域 |
| 叶面焦烤 | 冠域外层叶片吸收的宇宙辐射有余热 | 冠域 |

## 五、建筑与工具材料

| 材料 | 来源 | 用途 | 稀缺度 |
| --- | --- | --- | --- |
| 活木 | 引导须根/枝条生长成形 | 根域的建筑——"长出来的房子" | 低 |
| 树皮板 | 树干表面的老化树皮层 | 建材、盾牌 | 低 |
| 藤 | 安姆的藤条 | 万用——绳索、弓、桥、编甲 | 低 |
| 树脂 | 树液凝固 | 粘合、密封、容器、硬甲 | 低 |
| 骨 | 猎物/牲畜 | 刀刃、箭头、工具 | 中 |
| 石 | 台地岩层 | 石斧、石锤 | 中（开采可能伤及土层） |
| **泥土** | 地壳碎片残留 | **农业**——仅冠域有 | **极高（不可再生）** |
| **铁** | 泥土/岩层中的矿脉 | **武器、高级工具** | **极高（教会垄断冶炼）** |

### 铁器的社会意义

- 冠域贵族佩戴铁器 = 展示与教会的关系 = 展示权力
- 一把铁剑的价值可能等同于一块耕地
- 黑市铁器：存在地下冶炼工坊，用偷来的"野火"冶铁。被发现等同于叛教，处以极刑
- 根域完全没有铁——他们甚至不知道铁是什么。当天泽（或露维）第一次展示铁器时，根域居民可能以为那是某种"硬骨头"

## 六、一天的时间线

### 根域（以露维的部族为例）

| 时段 | 活动 | 感官锚点 |
| --- | --- | --- |
| 脉光潮来临前 | 在冷光菌落的微光中醒来，吃昨日采集的菌类 | 安静。没有烟火气，没有晨光 |
| 脉光潮（~3–5 小时） | 全部族出动——采集、修补藤桥、远距离侦察 | 树脉亮起，像地底的血管在发光。所有人抓紧时间 |
| 脉光潮退去 | 收回安全区，清点收获，修补光源 | 光线像潮水一样退去，黑暗重新合拢 |
| 长暗期 | 守光者值守，故事和歌声在黑暗中传递 | 偶尔远处传来暗季猎手的声响——所有人屏息 |

### 冠域（以普通农民为例）

| 时段 | 活动 | 感官锚点 |
| --- | --- | --- |
| 花开（昼） | 下田劳作——每一寸土都被精心照料 | 花光温暖，风从叶脉间吹来 |
| 正午 | 花光最盛，教会的钟声（树脂钟）报时 | 抬头看花——巨大到像另一个太阳 |
| 花合前 | 收工，赶在天黑前回到聚落 | 花瓣缓缓闭合，像一扇巨大的门在关上 |
| 花合（夜） | 树液灯亮起，家庭聚餐（无火烹饪），孩子听教会的故事 | 安静但不黑暗——树液灯的暖光笼罩聚落 |
