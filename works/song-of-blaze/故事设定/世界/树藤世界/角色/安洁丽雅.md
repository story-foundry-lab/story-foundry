# 安洁丽雅（丽雅）

## 一句话总结
露维身边那个永远比她多想一步的人——不是因为胆小，是因为她在乎的东西比露维以为的多。

---

## 基本信息

- **全名**：安洁丽雅
- **昵称**：丽雅（露维专用）
- **年龄**：与露维同龄，约十三岁
- **身份**：露维的搭档 / 室友

---

## 性格

### 核心特质：温柔的钉子
安洁丽雅从来不发火。她有一种本事——一句一句地把你堵到无话可说，语气不重，但堵得很实。

她的稳不是天生成熟，而是因为她总在替露维补后一眼：露维看菌子，她看脚底；露维看光，她先想路够不够走；露维说"没事"，她先看露维的手是不是在抖。

### 关键词
- **细心**：露维不看脚底下，她在后面盯着
- **讲究**：对吃的有一堆标准
- **嘴硬心软**：说"我不拦你"，但偷偷准备好干蘑菇
- **不抢话但不让步**：永远有下一句等着你

---

## 欲望 / 恐惧 / 底线

### 欲望：露维平安
听起来简单，但这个欲望会跟露维的好奇心产生**持续的结构性冲突**。露维越往外走，安洁丽雅就越紧。她不会拦（她知道拦不住），但她会越来越沉默——那种沉默比吵架更让露维难受。

### 恐惧：被丢下
不是被抛弃——是**露维走得越来越远，她跟不上**。露维看到异光、遇到天泽、接触到超出聚落认知的东西——这些安洁丽雅不是不想理解，是理解不了。她怕的是：有一天露维回来跟她说的话，她一句都接不上了。

### 底线
不要骗她。露维可以冲、可以犯蠢、可以不听劝——但不能骗她。"我没事"如果是假的，安洁丽雅发现了的话，会是两人关系最严重的裂痕。

---

## "如果……她会……"

| 情境 | 安洁丽雅的反应 |
|------|-------------|
| 露维又要去危险的地方 | 不拦。但会问一遍"带够东西了吗"。如果露维说带了，她会在包里再塞一份 |
| 露维一夜没回来 | 前半夜：坐着等。后半夜：去找格里朗。不哭，但嘴唇是白的 |
| 露维带回一个陌生人（天泽） | 第一反应：挡在露维前面。不是敌意——是本能。确认安全后才退开。之后会仔细观察天泽很久，不说话 |
| 部族逼露维把天泽送走 | 她知道大人们未必全错，但看到所有人都在逼露维时，还是会站到露维旁边。她站队不是被说服，是舍不得露维一个人挨 |
| 露维开始说她听不懂的事 | 沉默变多。不是生气——是在消化。过两天会冷不丁冒出一句精准到让露维震住的话 |
| 有人伤害露维 | 安洁丽雅生气的样子没人见过。不是因为她不生气——是因为她生气的时候**太安静了** |
| 露维骗了她 | 唯一会让她真正受伤的事。不会大吵，会变得客气。客气的安洁丽雅比愤怒的安洁丽雅可怕一百倍 |

## 说话方式

### 语言特征
1. **短句收尾，句句精准**——不啰嗦，但到位
2. **陈述句堵人**，几乎不用感叹号
3. **翻白眼、会笑，但不大喊大叫**
4. **记忆力好**——翻旧账翻得不让人讨厌
5. **偶尔毒舌**，但毒得有温度

### 怎么写她
- 她不抢露维的戏。她的存在感来自观察、补位和一句堵死人的短话。
- 担心不要写成反复唠叨。她会先检查东西带没带够，再把多余的干菌塞进去。
- 她的情绪常常延迟出现：当场很稳，事后才沉默、手冷、吃东西变慢。
- 她站在露维这边，不等于她觉得露维永远正确。这个矛盾要保留。

## 关系

| 对象 | 关系本质 | 张力 |
|------|---------|------|
| 露维 | 互补——一个冲一个稳 | 露维越走越远，她越来越跟不上。这是全书最大的慢性裂痕之一 |
| 天泽（未来） | 复杂 | 天泽分走了露维的注意力。不是嫉妒——是失落。她可能是最后一个接受天泽的人，但一旦接受，会是最坚定的 |
| 达恩 | 尊敬但不亲近 | 达恩绕着说话，安洁丽雅喜欢直接。两人不太聊得来 |
| 岩 | 微妙 | 两个都是观察者，两个都在用各自的方式保护露维。可能有一种无言的默契 |

---

## 剧情种子

1. **渐行渐远**——露维接触到越来越大的世界，安洁丽雅被留在原地。这条线如果处理好，比任何打斗都有张力
2. **安洁丽雅的爆发**——她一直在忍、在堵、在偷偷准备。如果有一天她忍不住了，那个瞬间会非常有力
3. **她自己的选择**——她不只是"露维的搭档"。如果有一天她必须独自做一个决定（比如露维不在时聚落出事），她会展现出露维不知道的那一面
4. **最后一个接受天泽的人，但最坚定**——因为她不是被感动，是被说服。而被说服的人不会再动摇

## 外貌
- 苍白偏灰的皮肤，手腕处蓝色血管隐约可见
- 一颗歪的虎牙（笑时露出）
- 粗黑麻花辫，编得紧实，尾巴甩到肩胛骨中间
- 比露维高半个头，肩膀更宽，小臂有刺背蜈留下的旧疤

## 写作避坑
1. **别让她只当"担心露维"的工具**——她有自己的好恶
2. **别让她变成碎嘴唠叨**——她话不多但有分量
3. **她和露维的裂痕是慢性的**——不是一次吵架，是渐渐的沉默
4. **别把站队写得太轻松**——她站到露维旁边时，心里应该知道这可能是错的
