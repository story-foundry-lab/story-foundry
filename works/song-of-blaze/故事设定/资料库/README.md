# 结构化资料库

这里用于存放或索引可结构化检索的角色、地点、势力、规则、物品等资料卡。

正式设定源仍在 `故事设定/世界/`，本目录不能覆盖角色卡、聚落设定、专项设定或正文事实。资料库条目如果和正式设定冲突，先修正式设定或正文，再同步资料库。

## Suggested Types

- `character`: 角色索引和当前作品内表现。
- `location`: 地点、聚落、地理。
- `faction`: 势力、组织、族群。
- `rule`: 能量体系、禁忌、世界规则。
- `item`: 重要物品、资源、媒介。
- `other`: 暂不能归类但需要检索的事实卡。

## Rules

- 不复制大段正文。
- 不把灵感片段直接提升为事实。
- 涉及天泽近卫时，先查 `shared/角色/天泽近卫.md`。
