# 互动试演

这里记录剧情分支、角色反应和现场桥段的试演结果。

互动试演默认不是正文事实。只有被整理进 `正文草稿/`、`故事设定/`、`剧情大纲/`、`剧情大纲/分章大纲/章节组/` 或 `项目管理/创作进度/` 后，才进入正式写作上下文。

## Record Format

```markdown
# YYYY-MM-DD：试演主题

## 试演问题

## 必读事实源

## 初始场景

## 试演回合

## 可合入项

## 仍需确认项

## 不进入正史的分支
```

## Rules

- 不替用户做重大选择。
- 不为了试演效果改写已确认设定。
- 可合入项必须再走正式编辑、章节组规划或设定维护 workflow。
