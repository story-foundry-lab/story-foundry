# 《炽炎的颂歌》文风规范

> 本文件是写作时的强制参考。所有新写、改写、审读均以此为准。
> SKILL.md 中的"写作硬规则"是本文件的精简版；本文件是完整版，带示例和判断标准。

---

## 一、叙事基调

第三人称有限视角，贴住POV人物的体感。

- **先身体，后意识**：先写露维感受到了什么（温度、触感、气味、声音、阻力），再写她判断了什么。不反过来。
- **不解释世界**：世界观信息通过人物的动作和感知自然流出，不做旁白式说明。
- **不代替读者总结**："她很害怕"是总结。"膝盖弯的时候卡住了"是体感。用后者。

### 基调参照

| 场景类型 | 基调 | 句长倾向 |
|----------|------|----------|
| 日常/出发 | 安静、细致、体感密集 | 中长句为主，偶尔短句做呼吸 |
| 路途/探索 | 好奇、微紧张 | 中等句长，感官叠加 |
| 追逐/战斗 | 急促、压迫 | 短句密集，动词链 |
| 凝视/接触 | 缓慢、庄重、敬畏 | 长句铺开，短句做锚点 |

## 二、段落密度

### 核心原则

**一个段落 = 一个完整的信息单元**，通常3-6句。

节奏变化靠句子长短交替，不靠换行。

### 什么时候可以单句成段

| 允许 | 不允许 |
|------|--------|
| 恐惧锚点（"露维定住了。"） | 普通动作（"她站起来。"） |
| 追逐启动（"露维跑了。"） | 普通观察（"前面是黑的。"） |
| 爆发节拍（"五步。"） | 情绪标签（"她很害怕。"） |
| 决心转折（"她没停。"） | 场景铺垫（"池子不大。"） |

判断标准：**这个句子如果接在上一段末尾，节奏会不会被吃掉？** 如果会，才独立。如果不会，合进去。

### 合并策略

- 同一动作序列归一段
- 同一瞬间的多感官体验归一段
- 判断紧跟触发它的观察，不另起段
- 段落断裂 = 时间/空间/注意力的真实切换

## 三、标点与节奏

### 破折号（——）

- **只用在节奏断裂点**：追逐中的突变、爆炸瞬间、恐惧高峰
- 补充说明用逗号分拆，同位解释用句号断开
- 全章密度：**每15-20行一个**
- 写完 grep 自查，超标就替换

### 句号 vs 逗号

密段中，信息连续推进时用逗号连接，到一个小结论或感官切换时用句号。

```
✗ 她闭了一下眼。眼皮后面是红的。血管的颜色。热透了的颜色。
✓ 她闭了一下眼，眼皮后面是红的，血管的颜色，热透了的颜色。
```

短句号断开适用于节奏需要（追逐/恐惧），不适用于静态描写和内心感受。

## 四、感官优先级

露维是体感型角色。她的感知通道排序：

1. **触觉/体温** — 脚底温度、皮肤上的风、手指触到的质感
2. **嗅觉** — 菌味、树液味、干辣味、聚落的闷味
3. **听觉** — 脚步声、呼吸声、水泡声、鳞片声
4. **视觉** — 最后才是"看到了什么"（而且暗期视觉受限，更依赖前三者）

写环境描写时，先从触觉/嗅觉入手，再叠加听觉，最后视觉。不要默认从视觉开始。

## 五、比喻边界

### POV认知限制

所有比喻必须在POV人物的生活经验内。

**露维可用的比喻素材**：
菌类（冷光菌、夜菌、菌盖、菌丝）、树皮/树液/苔藓、藤条/藤编、虫（萤虫、刺背蜈、钩爪猴）、水/雾/露、聚落日常器物（藤绳袋、刮片、萤瓶、树脂匣子）

**露维不可用的比喻素材**：
旅人、城市、书本、金属器具（她的世界没有冶炼）、火（她没见过火，至少在接触天泽之前）、任何需要广阔视野的意象（地平线、大海、沙漠）

### 自查方法

写完比喻后问：**露维在哪里见过这个东西？** 答不上来就换。

## 六、信息控制

### 意象重复上限

同一个意象描述（如"脉动一收一放"），全章最多**2次**。

第3次必须：
- 换新信息（从脉动→形状变化/颜色变化/声音变化）
- 或砍掉

### 物品权重

有前置铺垫的物品，其状态变化必须有等比例的戏剧逻辑：

| 铺垫重量 | 丢失/变化要求 |
|----------|---------------|
| 重（萤瓶：偷取过程写了整段） | 丢失必须有物理原因（绊倒）+ 情感犹豫（想回去捡）+ 后续交代（第三章找回） |
| 中（干菌包：一句交代） | 提一句存在感即可 |
| 轻（藤鞋：半句） | 不需要单独交代 |

### 排比禁令

禁止三连排比抒情（"想X，想Y，想Z"）。

替代方案：
- 用一句物理细节代替（"她闻到自己头发上聚落的味道"）
- 用一个短判断收束（"她非常想回去。"）

## 七、空间逻辑

多实体场景（兽+露维+光源）必须交代清楚：

- **谁在哪**：前后左右，用步数标定距离
- **力从哪来**：爆炸/冲击的来源方向、经过谁、打到谁
- **谁往哪动**：冲刺方向、退却方向、绕行路线

每个动作段写完后，画一个心理草图：**如果按文字描述摆物理模型，有没有矛盾？**

---

## 八、对话处理

露维对话少，但规则通用：

- 对话不孤立成段，前后接动作/体感
- 单句对话 + 反应 = 同一段
- 多人快速交谈可聚合一段（群像嗡嗡声效果）
- 对话中穿插小动作（摸瓶子、看脚下、抠树皮），不写纯对话行

---

## 九、内心独白

- 嵌入叙述段落，不单独拎出做"OS段"
- 露维的判断通过体感反应表达，不通过思维分析

| 避免 | 替代 |
|------|------|
| "她意识到这很危险" | "后脖子上的汗毛竖了起来" |
| "她觉得它不会伤害她" | "热是真的。但如果它想伤她，早就伤了。" |
| "她下定决心" | "她没停。" |

- 紧张后的节奏释放：用"身体还在日常运转但意识已脱轨"的反差（攥碎的干菌、自动捡起刮片别回腰上）

## 十、自查清单

每次写完/改完，过一遍：

- [ ] 破折号数量（`grep -c '——'`，目标：总行数 ÷ 15~20）
- [ ] 单句成段数量（是不是只在锚点位置？）
- [ ] 意象重复（搜关键词，同一描述是否超过2次）
- [ ] 比喻越界（露维见过这个东西吗？）
- [ ] 空间逻辑（画位置关系，有没有矛盾）
- [ ] 排比抒情（有没有三连"想/要/像"）
- [ ] 情绪标签（有没有直接写"害怕/难过/开心"而不走体感）
