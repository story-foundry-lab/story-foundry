# 琥珀之剑参考入口

本目录保存《琥珀之剑》的章节定位、风格拆解和可迁移写法，用于指导《炽炎的颂歌》的文风优化。

## 文件索引

| 文件 | 用途 |
|---|---|
| `QQ阅读章节索引.md` | 记录本轮筛出的重点章节、QQ 阅读 URL、学习目标 |
| `专题拆解/布兰多-小女孩-领主线.md` | 重点拆解“救下小女孩 -> 面对格鲁丁/领主压力 -> 建立旗帜感”的章节组 |
| `专题拆解/魔力之潮与火种设定.md` | 拆解魔力、要素、火种、极境战斗等设定如何嵌入叙事 |
| `专题拆解/待定位-教堂目睹杀人.md` | 记录“教堂目睹杀人”疑似场景的定位线索和后续核对清单 |
| `专题拆解/简书早期笔记.md` | 从简书「灵感集」导入的早期阅读印象，保留为低优先级参考 |

## 使用方式

1. 定位章节：优先看 `QQ阅读章节索引.md`。
2. 写笔记：放到 `专题拆解/` 或新建同级专题文件。
3. 迁移写法：只迁移叙事方法，不迁移专有设定、人物关系和句子表面。
4. Public 仓库不提交第三方作品全文、批量原文节选或抓取语料。

## 本轮优先读法

优先读两条线：

- 布兰多的“骑士性”：先保护具体的人，再把个人行动升级成可追随的旗帜。
- 设定的“战斗化”：魔力、要素、火种不是百科条目，而是在危险、决断、代价和旁观者震撼中被读者理解。
