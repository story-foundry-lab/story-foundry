## 视觉原则

- 画风基准是原创手绘日式动画电影感 / 轻小说奇幻世界观设定，不直接模仿特定画师。
- 构图优先清晰和留白：少元素、少拆解框，避免百科式拥挤设定板。
- 人物和生活场景保留二次元清亮感：轮廓干净、色彩通透、情绪温柔。
- 聚落不是木屋村，而是依附在活体安姆组织上的藤编生存结构。
- 光源以叶雾漫射光、萤瓶、发光虫为主，不能出现火把、蜡烛或炉火。
- 生活质感应偏潮湿、节俭、修修补补，不走富裕精灵城市路线。
- 拆解图中的图形标记仅作视觉索引，不依赖图内文字。

## 章节插画规范

- 章节插画延续设定图画风：手绘动画电影感、轻小说奇幻、干净轮廓、通透色彩，不能转向照片级写实、3D 渲染或黑暗恐怖海报。
- 插画可以比设定图更有剧情情绪，但情绪来自构图、人物动作和光色对比，不靠血腥、脏污、惊悚脸部特写、湿黏腐烂质感或过度阴影。
- 优先选择章节中的关键转折场景：人物做出选择、第一次看见新规则、世界观意象显形；普通日常段落不强行配图。
- 单章最多一张正文插图，放在场景进入高潮前后，不能打断最后一句、悬念句或强情绪落点。
- 主体要服务文本：人物年龄、衣着、藤鞋、藤绳袋、萤瓶、菌光、藤编结构、活体树皮等细节必须贴合正文和世界设定。
- 红橙高热光只能作为特殊事件光源使用；常规场景仍以叶雾漫射光、青白菌光、蓝色萤瓶和发光虫为主。
- 画面要保持干净的空气感：避免大面积黑泥色、高反差黑根、密集脏线、油腻反光和暗黑游戏概念图质感。
- 画面中不得出现现代物、金属城市感、火把、蜡烛、炉火、图内文字、水印、Logo。
