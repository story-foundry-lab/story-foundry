# 情节素材：故事内核

本目录只保留能继续服务《炽炎的颂歌》的情节内核和少量场景卡。这里不是正式设定源，写正文或大纲时仍以角色卡、世界设定、分幕大纲和总纲为准。

## 故事内核

### 1. 旅者不能成为新的神

天泽可以介入、开路、切断失控回路，也可以把火带进一个只有冷光和禁火秩序的世界。但她不能替树藤世界接管未来。

她的成长不是从弱变强，而是从“我只是路过”变成“我已经在这里”。她被露维、部族、旅途和这个世界的痛苦改变，于是必须承认：不作为也是选择。可她最终仍要把决定权交还给树藤世界的人。

可用写法：

- 天泽犹豫时，不让她讲宏大道理，而让露维用很短的话把她拽回现场。
- 天泽每一次用火，都要带来代价：暴露、灼伤、刺激安姆、加剧冲突。
- 终局不能写成天泽替所有人解决问题，只能写成她创造一个让本世界角色能行动的缺口。

### 2. 露维要作为自己活着

露维的主线不是“被治好”，而是拒绝被丰饶系统改写成一个更健康、更温顺、更不像自己的人。

冠域的快速治疗必须真实有效，否则她的拒绝没有重量。万生之泽能止痛、延寿、修复身体，也能让人逐渐失去愤怒、悲伤、拒绝和自我边界。露维拒绝的不是活下去，而是那种没有自己的活法。

可用写法：

- 她面对治疗诱惑时，不先讲理念，先感到害怕、心动、疲惫，再做选择。
- 她的盾牌不是“主角能力”，而是她想保护身边人的念想外化。
- 她证明自己的方式是行动：伸手、挡住、留下、带路，而不是宣言。

### 3. 丰饶不是恶，失去边界才可怕

安姆、赐福、冠域医疗都不能写成单纯骗局。它们真的救过人，真的让文明繁荣过。恐怖点在于它们太有效，导致人们越来越不能接受疼痛、衰老、等待和拒绝。

可用写法：

- 冠域初登场要先美、亮、有效，后面再显出代价。
- 被赐福者不是怪物素材，而是“曾经被救过的人”。
- 教会不能只有坏人，也要有相信治疗、试图改革、被制度拖住的人。

### 4. 世界由世界里的人接住

最后的证明必须是接力，不是单人救世。

根域人证明没有恩泽也能活；冠域人证明治疗可以重新变成过程；承泽者证明他们仍能拒绝；露维用盾牌护住众人；天泽只在必要处切开道路。

这条链条一旦断掉，主题就会滑向外来者救世。

## 使用边界

- `sparks/情节` 只提供可选素材，不反向覆盖正式设定。
- 外部作品灵感只保留转化后的功能，不保留原作品剧情、歌词或设定。
- 不再保留大段“战斗参考”。需要动作场景时，先看当前幕的动机、空间、代价，再设计动作。
- 幻想具现暂时只作为露维“守护念想外化”的写法参考，不在本目录扩展成完整战斗系统。
