## 待校准点

以下内容和最新写作方向有冲突，写第三章前必须修：

1. **不要再用“安姆的暖/脚下往前涌”作为露维靠近天泽的主动力。**
   - 用户已明确不喜欢“安姆的暖”作为行动引导。
   - 第三章可以保留“安姆没有防御反应/周围藤蔓没有攻击”这种环境许可，但不要写成树皮温度推动她。
   - 更稳的动机链：暗鳞兽已退 -> 光团没有追她/攻击她 -> 它刚才击退了威胁 -> 露维已伸手且被注意到 -> 好奇和“没找到必须退的理由”继续推动她。

2. **不要写光脚/脚趾细节。**
   - 当前最新设定是露维穿薄底藤鞋。
   - 天泽化形时，大纲写“赤脚踩进浅水”，需要改写。可改为“脚落进浅水”或用衣物/水面反应带过，不强调脚。

3. **不要让天泽外表过度神化。**
   - 不写光纹、异色瞳、无毛孔、极致美貌。
   - 神性主要靠行为泄露：沉默、不接话、目光不闪避、不找路、不吃不睡、动作轻。

4. **不要让露维提前理解“火”或天泽本质。**
   - 她可以感到热、干、亮、危险后变可承受。
   - 不能直接判断“这是火/这是天泽的能力/这是近卫”。

5. **名字只给“天泽”，不出现“近卫”。**
   - “近卫”是后续关系和使命变化后才长出来的称呼。

## 建议改写后的第三章逻辑

推荐按以下顺序写：

1. 接第二章章尾：露维手还伸着，赤红核心停了一拍后继续脉动。
2. 露维想退，但身后的黑、丢失的萤瓶、刚逃走的怪物让原路并不立刻安全。
3. 核心没有逼近、没有追她，也没有像怪物那样压低身体或蓄力。
4. 赤红逐渐收拢，蒸汽退开，露维先看到“人的轮廓”，再看到“是个女孩”。
5. 化形过程要短，不做设定说明。用露维可感知的画面：水面、热气、轮廓、衣物、头发、站姿。
6. 露维先开口。问题要朴素，不讲大道理，例如“你是谁？”“你没事吧？”二选一即可。
7. 天泽不回答，只偏头/看她/确认声音来源。
8. 露维靠近不是因为勇敢，而是因为对方没有做出危险动作。
9. 命名触发点要实用：总得有个叫法。露维根据“从天上掉进水泽”给出“天泽”。
10. 带回动机：天泽不找路、不找食物、不往任何地方去；露维已经管上了，就放不下手。
11. 回程必须处理萤瓶：莫砾的瓶子不能丢。天泽残留的微光可以帮露维看见萤瓶，但露维不要立刻总结“她有用”。
