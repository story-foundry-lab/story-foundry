# Agent Surface

`.agents/` 保存 agent 如何工作的契约，不保存作品正文或设定资产。

- `skills/`: agent skills 和参考清单；写作权威入口仍是 `skills/novel-fiction/SKILL.md`，发布流程入口是 `skills/publish-pr-flow/SKILL.md`。
- `protocols/`: 仓库协议、作品生命周期和 public hygiene。
- `workflows/`: 可执行任务流程。

写作协作规范唯一权威来源是 `.agents/skills/novel-fiction/SKILL.md`。
