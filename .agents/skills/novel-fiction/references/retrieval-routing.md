# 检索与图谱路由

用于角色、设定、世界观、章节衔接、设定冲突和跨文件同步。

## 原则

- 图谱或检索只负责初筛和导航，不负责定稿事实。
- 定稿事实必须回到正式文件原文。
- 搜索结果不能替代角色卡、设定、大纲和正文上下文。

## 常用命令

```bash
rg -n "<关键词>" works/song-of-blaze
rg --files works/song-of-blaze | rg "<路径关键词>"
```

## 检索步骤

1. 用关键词找候选文件。
2. 读取候选文件的相关段落。
3. 回到 `ka.yaml.paths` 确认该文件是否属于正式事实源。
4. 如候选来自灵感片段或旧稿，只作为参考，不直接定稿。

## 判断输出

回答设定问题时注明依据来自哪里：

- 角色卡：可作为强依据。
- 专项设定：可作为强依据。
- 大纲：用于剧情方向，不能覆盖角色卡。
- 灵感片段：只作候选。
- 旧稿：只作历史参考。
