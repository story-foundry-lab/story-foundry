# 插画生成与插入

用于插画、配图、视觉设定和 Markdown 图片插入。

## 原则

- 插画不作为正式设定来源。
- 正式外观仍以角色卡和设定文件为准。
- public 仓库不提交来源不明或授权不清的第三方图片。
- 生成图需要标注用途和来源。

## 流程

1. 读取相关正文、角色卡和视觉资产说明。
2. 提取可视要素：人物、场景、光源、动作、氛围。
3. 生成或整理图片。
4. 图片放入作品资产目录，不混入正文目录。
5. Markdown 中使用相对路径，并说明图片用途。

## 提示词边界

- 不把未定设定写死为“正式外观”。
- 不把参考作品角色直接复刻。
- 不生成露骨、侵权或不适合 public 仓库的内容。
