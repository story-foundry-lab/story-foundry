# 插画生成与插入

## 何时使用

用户提到插画、配图、生成图、画风、图片插入 Markdown，或要求为章节选择视觉场景时使用本文件。

## 先读什么

1. 读取目标章节相关段落，确认场景、人物、物件、光源和尺寸。
2. 读取项目内现有视觉资产规范；`炽炎的颂歌` 默认读取 `works/song-of-blaze/故事设定/世界/树藤世界/assets/设定图/README.md`。
3. 如已有同世界图片，先抽看 1-3 张，不凭抽象词判断画风。

## 场景选择

- 优先选择章节转折点：人物做出选择、第一次看见新规则、世界观意象显形。
- 不给普通日常段落强行配图；一章通常最多一张。
- 插图放在视觉场景完整展开前后，不能打断最后一句、悬念句或强情绪落点。

## 风格转译

不要在生成提示中直接要求模仿特定在世艺术家或导演。用户说“宫崎骏感”时，转译为：

- 经典手绘日式动画电影感。
- 透明水彩 / 背景美术质感。
- 清亮轮廓、干净人物剪影、可读性强的环境层次。
- 童话感、生活感、自然生命力里带一点危险。
- 温柔但不幼稚，奇幻但不脏、不恐怖。

## 树藤世界画面底线

必须避免：

- 照片级写实、3D 渲染、电影恐怖海报、暗黑游戏概念图。
- 大面积黑泥色、高反差黑根、湿黏腐烂质感、密集脏线、油腻反光。
- 血腥、惊悚脸部特写、怪物压迫主体、过度阴影。
- 火把、蜡烛、炉火、现代物、金属城市感、图内文字、水印、Logo。

应当保留：

- 活体树皮、藤编结构、苔藓、叶雾、菌光、萤瓶、发光虫。
- 潮湿但干净的生活质感，不是腐败、肮脏或恐怖。
- 留白和空气感；画面元素少而明确，不堆满根须和暗部纹理。
- 人物年龄、衣着、藤鞋、藤绳袋等正文细节。

## 生成前自检

- 关键物尺寸是否和正文一致，例如赤光是一人大小就不能画成头大小。
- 光源是否符合设定；红橙光只能作为特殊事件光源，常规场景以叶雾漫射光、菌光、萤瓶和发光虫为主。
- 怪物若出现，通常放在远景或边缘，不抢走章节意象。

## 插入规则

- 生成图未通过画风自检前，不插入正文。
- 图片复制到项目目录，保留原生成目录，不移动或删除原图。
- Markdown 使用相对路径。
- 插入后回读前后 3-5 段，确认图片不会破坏阅读节奏。
