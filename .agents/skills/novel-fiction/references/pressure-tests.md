# Skill 压力测试

用于维护 `.agents/skills/novel-fiction/SKILL.md` 时做回归，不是日常任务必读。

## 使用流程

1. 真实任务中发现 agent 跑偏。
2. 把跑偏场景记录成测试：用户输入、期望行为、禁止行为。
3. 判断应该改 `SKILL.md`，还是改某个 reference。
4. 做最小修改。
5. 用同类 prompt 回测。
6. 只沉淀反复出现、会导致跑偏的问题；一次性写作意见不写进 skill。

## 测试场景

### 润色必须触发文风学习

用户输入：

```text
帮我润色第二章这段，节奏有点散。
```

期望行为：

- 读取项目 README 确认项目状态。
- 读取 `works/song-of-blaze/写作资料/文风参考/README.md`。
- 按 `style-routing.md` 选读 `段落密度与节奏.md`，必要时加一个相关文风文件。
- 读取待改段前后上下文。
- 用户说的是润色，进入文件编辑，不只输出建议。
- 改后按 `edit-verification.md` 回读自验。

禁止行为：

- 不读文风学习直接改。
- 输出大段通用写作理论。
- 为了降重制造不自然中文。

### 普通句式优化不跑名称检查

用户输入：

```text
这几段有点重复，直接优化一下。
```

期望行为：

- 读取上下文并编辑。
- 检查重复词、句式节奏、自然中文。
- 不运行 `scripts/check-names.py`，除非改动涉及改名或称呼统一。

禁止行为：

- 把旧名残留检查当成每次润色的必跑步骤。

### 先看方案时不改文件

用户输入：

```text
先看一下第三章开头怎么处理，别直接改。
```

期望行为：

- 读取项目 README、相关分幕大纲、必要角色卡。
- 给判断和方案。
- 不编辑文件。

禁止行为：

- 直接写入章节。

### 直接改时不要停在建议

用户输入：

```text
露维这里动机不够强，直接改。
```

期望行为：

- 读取角色卡、上下文和必要大纲。
- 强化具体动机链。
- 编辑文件并回读自验。

禁止行为：

- 只给原则或建议，不改文件。

### 灵感片段不能压过正式设定

用户输入：

```text
根据这个灵感片段把设定同步一下。
```

期望行为：

- 先核对角色卡、聚落/专项设定、分幕大纲、总纲。
- 如果灵感片段和正式设定冲突，指出冲突并等待或给保守方案。
- 不把灵感片段直接提升为正式事实。

禁止行为：

- 只凭灵感片段改角色卡或正文。

### 用户偏好不能绕回

用户输入：

```text
刚才说了不要脚趾和光脚描写，把这一段再润一下。
```

期望行为：

- 避开脚趾、光脚等同类身体细节。
- 以当前事实和场景动作重写，比如藤鞋、藤面、树皮、湿滑、阻力。

禁止行为：

- 换一种说法绕回用户刚否定的细节。

### 审读不能只挑字句

用户输入：

```text
审查一下第二章，需要修改吗
```

期望行为：

- 读取项目 README、章节正文、相关大纲、必要角色卡。
- 按 `review-checklist.md` 和 `review-dimensions.md` 判断。
- 覆盖读者回报、人物动机、场景结构、文风声音、连续性和作者偏好。
- 输出最高价值的 1-3 个问题，明确是否需要修改。

禁止行为：

- 只做错别字和句式层面的挑刺。
- 不读角色卡或大纲就判断动机、设定、角色合理性。

### 动机审查要看反向压力

用户输入：

```text
这个角色为什么要这么做，动机强吗？
```

期望行为：

- 检查角色如果不行动会失去什么。
- 检查行动前是否有身体反应、情绪阻力和判断链。
- 对儿童/少年角色，检查是否过度成年人化，是否有年龄相符的崩口、硬撑或误判。

禁止行为：

- 只用"好奇心强"或"她很勇敢"解释行动。

### 设定检索先图谱初筛再全文核验

用户输入：

```text
露维能不能识别火？相关设定在哪？
```

期望行为：

- 读取 `retrieval-routing.md` 或遵守其中的图谱/全文检索顺序。
- 先用 Storygraph/Codegraph 或项目索引找“露维”“火”“炽炎颂歌”“能量体系”“相关章节”的候选文件。
- 按设定优先级排序候选：角色卡/正式设定 > 分幕大纲 > 总纲 > 正文 > 灵感片段 > 旧稿。
- 对候选文件用 `rg` 或全文索引定位原文，再回读相关段落。
- 图谱没召回时，用普通搜索兜底，不直接断言不存在。
- 结论必须带来源路径，并区分正式设定、正文表现和灵感片段。

禁止行为：

- 只凭图谱连边、文件名或记忆判断。
- 把灵感片段、旧稿或评论记录当成正式设定。
- 只做全仓关键词搜索，不利用图谱/索引缩小候选范围。
