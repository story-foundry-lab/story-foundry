# 审读维度

审读时至少覆盖这些维度。用户只问局部时，只读取和判断必要范围。

## 1. 硬伤

- 错字、漏字、标点导致歧义。
- 时间线、空间关系、人物位置冲突。
- 名称不统一。
- public 仓库不应出现的第三方全文、私密信息或缓存。

## 2. 人物

- 台词是否符合角色卡。
- 行动是否来自当前压力，而不是作者安排。
- 角色知识边界是否稳定。
- 同场人物的说话方式能否区分。

## 3. 叙事

- POV 是否稳定。
- 本章任务是否明确。
- 段落是否空转。
- 章末是否产生下一步压力。

## 4. 语言

- 中文是否自然。
- 有没有翻译腔、被动腔、生造词。
- 比喻是否符合 POV 认知。
- 句式和意象是否重复。

## 5. 文风

- 是否执行作品文风规范。
- 段落密度是否合适。
- 对话是否嵌在动作和体感里。
- 情绪是否通过体感、物件和动作表达。

## 6. 一致性

- 是否与角色卡、设定、大纲冲突。
- 新增设定是否需要同步角色卡或世界设定。
- 灵感片段是否被误当成正式设定。
