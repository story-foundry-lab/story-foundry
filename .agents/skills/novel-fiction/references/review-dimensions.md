# 小说质量审查维度

用于整章审读、场景判断、改前诊断和改后复盘。它不是评分表；先找最影响阅读和后续创作的 1-3 个问题。

## 1. 读者回报

读者是否愿意继续读。

- 这一章/这一场给读者的核心回报是什么：悬念、危险、情绪、关系变化、信息揭示，还是新奇世界？
- 开头是否快速给出阅读抓手，结尾是否留下继续读的牵引？
- 哪些地方会让读者卡住：看不懂、不信、无聊、信息太密、情绪不连贯？
- 类型承诺是否兑现：奇幻感、危险感、人物关系和世界新鲜度是否足够？

## 2. 人物与动机

角色行动是否由自己的欲望、压力、恐惧、误判或价值观推出。

- 角色为什么现在行动？如果不行动，会损失什么？
- 动机是否具体，是否落到可感事物：食物、伤痛、关系、代价、规矩、恐惧、好奇？
- 角色是否像自己，而不是像作者推剧情的工具？
- 情绪是否有年龄、经验和处境的重量；小孩不能长期像成年人一样稳定。
- 行动是否有判断链：看到什么 -> 身体怎么反应 -> 怎么判断 -> 怎么动。

## 3. 场景与结构

每一场都要完成任务。

- 这一场完成了什么：推进情节、改变关系、暴露风险、获得信息、制造代价、建立悬念？
- 冲突是否升级，障碍是否迫使角色做选择？
- 事件之间是否有因果，而不是单纯"然后又发生了"？
- 是否有空转段：漂亮但不改变情节、人物、关系或读者理解？
- 章节是否有清晰弧线：进入时什么状态，离开时什么状态改变了？

## 4. 文风与声音

语言是否贴住 POV、场景和本书气质。

- POV 是否稳定，是否先写体感和动作，再写判断？
- 句子是否自然中文；有没有为了降重造成被动腔、翻译腔、硬倒装？
- 比喻是否在 POV 角色认知边界内？
- 段落密度是否匹配场景：日常可密，追逐可短，凝视可慢，但都不能乱碎。
- 重复意象是否有新信息；同一意象第三次出现必须换角度或删除。

## 5. 连续性与设定

正文是否和正式资料一致。

- 角色卡、聚落/专项设定、分幕大纲、总纲是否冲突？
- 是否偷跑后文信息，或把 sparks 提升为正式事实？
- 称呼、道具、地理、时间线、能力表现是否前后一致？
- 新增设定是否需要同步角色卡、大纲或世界观文件？

## 6. 作者偏好适配

检查是否符合本项目已确认偏好。

- 自然中文优先。
- 强动机优先，尤其是具体损失和现实压力。
- 露维要会先动，但不是不怕；她会怕、会硬撑、会算小账。
- 避免用户明确否定过的身体细节和表达路径。
- 不靠神秘感替代人物行动，不靠设定说明替代场景推进。

## 使用方式

- 完整审读：五个维度都扫一遍，但输出只抓最高价值问题。
- 单点问题：只使用对应维度，例如"动机够不够"只重点看人物与动机。
- 直接改：把这些维度作为内部自验，不输出长篇理论。
