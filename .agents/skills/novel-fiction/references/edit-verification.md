# 正文编辑后自验

用于正文润色、改写、续写、新增场景和局部重写。完成编辑后，必须回读改动段前后至少 3-5 段。

## 回读检查

- 动机链是否连贯：角色为什么现在行动，压力是否具体。
- 空间关系是否清楚：谁在什么位置，动作如何承接。
- 视角是否贴住 POV 角色，有无全知越界或替角色解释世界。
- 角色言行是否符合角色卡，知识边界是否稳定。
- 是否偷跑后文信息，或引入未确认设定。
- 句子是否像自然中文，有无被动腔、翻译腔、不自然倒装。
- 是否引入新的重复词、重复动作或重复意象。
- 是否踩到用户本轮刚否定过的表达、设定或动作细节。

## 续写/新内容额外检查

- 新内容是否完成当前场景任务，而不是只增加气氛。
- 新动作是否由角色欲望、压力、处境推出。
- 新术语、比喻、判断是否在 POV 角色认知边界内。
- 是否需要同步角色卡、设定或大纲；普通句子润色不扩散。

## 完成说明

- 小改：最终简短说明改了什么和自验结果。
- 大改：说明主要改动、仍需用户判断的开放点。
- 如果发现设定冲突或角色卡缺口，先说明风险，不硬编补齐。
