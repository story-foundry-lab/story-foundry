# 编辑后自验

用于正文编辑、润色、续写和局部改稿后的自查。

## 必查

1. 回读改动段前后 3-5 段。
2. 确认 POV 没有漂移。
3. 确认人物动机、空间位置、物件状态没有被改乱。
4. 确认改动没有引入旧名、废名或称呼不一致。
5. 确认没有把灵感片段、未定设定写成正式事实。

## 文风自查

- 段落是否过碎。
- 对白是否孤立漂浮。
- 是否有翻译腔或不自然倒装。
- 情绪是否通过体感和动作表达。
- 比喻是否符合 POV 人物认知。

## 需要运行脚本的情况

名称迁移、结构协议、跨文件同步后运行：

```bash
python scripts/check-structure.py
python scripts/check-names.py --work song-of-blaze
```

普通单段润色不必机械跑全量脚本，但必须回读上下文。
