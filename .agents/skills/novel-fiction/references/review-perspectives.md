# 三重审查视角

用于高标准审读、章节复盘、改前判断、改后自验。不要替代项目文件；涉及事实、设定、角色时仍以角色卡、聚落/专项设定、分幕大纲、总纲为准。

完整审查先按 `review-dimensions.md` 找问题，再用本文件的三种视角判断优先级和表达方式。

## 读者视角

检查读者是否愿意继续读：

- 这一段最直接的阅读阻力是什么：看不懂、不信、无聊、节奏散，还是信息太密？
- 角色为什么现在行动，读者能否在当下感到压力？
- 空间关系、动作承接、对话归属是否清楚？
- 情绪是否有阶梯，还是只有同一种语气反复加重？
- 章节或场景末尾是否留下继续读的牵引力？

## 小说编辑视角

检查结构和叙事效率：

- 读者回报是否明确：这一章给了危险、情绪、关系变化、信息揭示还是世界新鲜度？
- 这一场有没有明确任务：取得信息、改变关系、暴露风险、推动选择，至少要完成一个。
- 冲突是否有效：不是吵闹或神秘感，而是人物目标和阻力真实相撞。
- 动机链是否连贯：看到什么 -> 判断什么 -> 害怕或想要什么 -> 采取什么行动。
- 信息释放是否过早、过密或重复，是否用设定说明替代了动作和体感。
- 角色对话是否符合角色卡：关注点、句子长短、知识边界、同场区分度。
- 段落密度是否匹配任务：动作场景更短更快，氛围段可以慢，但不能空转。

## 作者偏好视角

检查是否符合本项目已确认的写作偏好：

- 自然中文优先。不为了降重写被动腔、翻译腔或不自然倒装。
- 动机要具体，优先落到损失、压力、账本、食物、风险、关系代价等可感事物。
- 露维要写成会先动的人，行动来自她的处境判断和小账本，不靠外部神秘感硬推。
- 默认贴近有限视角，先写体感、动作、声音、气味、距离和阻力，不替人物解释世界。
- 不写脚趾、光脚等被用户明确否定过的身体细节；当前事实以藤鞋为主。
- 不用大段设定说明压过当下场景，不把灵感片段当成高于正式设定的事实源。
- 处理重复词时先保证语义清楚，再处理节奏，最后才压词频。

## 输出取舍

- 用户只是问"看下"：直接给结论和最值得改的点，不展开全部理论。
- 用户要求完整审读：按 `review-checklist.md` 输出。
- 用户要求直接改：把三重视角作为内部检查，最终只说明关键改动。
