# 文风学习选读路由

用户提到文风、润色、语言、生硬、流水账、节奏、对话、氛围、动作场景、风格像不像时使用。

先读：

```text
works/<work-id>/style/writing-style/README.md
```

再按任务选读 1-2 个对应文件，不要一次性全读。

## 选读表

| 用户任务 | 优先选读 |
|---|---|
| 整体文风、风格像不像、统一语言气质 | `炽炎的颂歌_文风规范.md` |
| 视角、内心、感知贴身、全知感过重 | `视角与内心.md` |
| 对话、生硬对白、叙述和对白衔接 | `对话与叙述混排.md` |
| 动作场景、追逐、搏斗、逃跑、身体阻力 | `动作场景写法.md` |
| 氛围、环境、压迫感、静场景 | `氛围铺陈.md` |
| 段落节奏、流水账、密度、场景推进 | `段落密度与节奏.md` |
| 通用写作判断、删改意识 | `斯蒂芬金_写作这回事.md` |

## 使用原则

- 文风文件用于约束句式、段落密度、视角和叙事节奏，不机械套模板。
- 先解决动机链、空间关系、视角，再处理词句。
- 自然中文优先。必要主语可以保留，不为了降重制造别扭表达。
- 用户要求直接改时，不输出文风理论；读完后进入编辑。
