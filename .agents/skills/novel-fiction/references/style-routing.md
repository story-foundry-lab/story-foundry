# 文风路由

用户提到“文风、语言、节奏、对白、氛围、动作场景、生硬、翻译腔”时，先读作品 `ka.yaml.paths.style` 指向的 README，再按问题选读下列文件。

默认作品 `works/song-of-blaze/` 的文风资料在：

`works/song-of-blaze/写作资料/文风参考/`

## 路由表

| 用户问题 | 读取文件 | 关注点 |
|---|---|---|
| 整体文风不稳 | `炽炎的颂歌_文风规范.md` | POV、段落密度、比喻边界、自查清单 |
| 段落太碎/太散 | `段落密度与节奏.md` | 信息单元、单句成段、句长变化 |
| 对话生硬 | `对话与叙述混排.md` | 对话和动作混排、群体对话 |
| 动作/战斗不清 | `动作场景写法.md` | 动作链、空间方向、体感锚点 |
| 氛围不足 | `氛围铺陈.md` | 感官顺序、静动对比、环境压力 |
| 内心太直白 | `视角与内心.md` | 内心嵌入叙述、体感替代标签 |
| 写作法则复盘 | `斯蒂芬金_写作这回事.md` | 删弱、清晰、读者体验 |

## 处理原则

- 文风文件只指导写法，不替代角色卡和设定。
- 每次最多选 1-2 个文风文件，避免把局部润色变成全套审查。
- 改稿时先解决影响理解的问题，再处理漂亮不漂亮。
