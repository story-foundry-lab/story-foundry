# 分幕重写监督清单

用于第一幕、整幕、多章连续重写和子 agent/worker 监督。目标是让重写有可验收的章节任务、场景压力、人物选择和跨章递进，而不是只把语言整体翻新。

## 总验收

每一章至少满足：

- 有明确章节任务，不只写情绪或氛围。
- 有来自本作品设定的空间锚点、时间压力或资源压力。
- 人物正在做事：寻找、隐藏、交换、阻拦、试探、选择、承担后果。
- 关键物件、关系、线索或规则至少有一项发生变化。
- POV 稳定，不偷跑后文信息。
- 角色言行符合角色卡，不能为了推进剧情让人物突然失真。
- 世界观信息落在动作、物件和阻力里，不靠旁白讲设定。
- 章末落在具体风险或选择上，不用主题句收束。

## 章节监督表

重写前先填这个表，允许简短：

| 章节 | 章节任务 | 必读依据 | 场景锚点/压力 | 物件/关系变化 | 角色选择 | 禁区 |
|---|---|---|---|---|---|---|
| 第 X 章 |  |  |  |  |  |  |

说明：

- `章节任务` 写“本章必须推进什么”，不是写主题。
- `必读依据` 指向章纲、角色卡、设定或上一章/下一章。
- `场景锚点/压力` 来自本作品事实源，不从其他项目照搬。
- `禁区` 记录用户本轮否定过的写法、未核验设定、public 仓库不能接收的内容。

## 重写步骤

1. 读 `WORKFLOW.md`、作品 `README.md`、`ka.yaml`、状态文件。
2. 读目标幕/章节对应的大纲、角色卡、必要设定和前后章。
3. 给每章写 3-5 条验收条件。
4. 逐章处理：先补任务、阻力和物件变化，再做语言整理。
5. 每章完成后回读前后章衔接。
6. 整幕完成后按 `review-dimensions.md`、`review-perspectives.md` 和 `edit-verification.md` 自验。

## Worker 监督

如果交给外部 worker：

- 先让 worker 填章节监督表，再产出草稿。
- Worker 不能直接覆盖正式章节。
- Worker 输出必须说明已读取文件和未解决风险。
- 主线程合入前要检查跨章连锁影响。

## 禁止写法

- 只加几个设定名词，不让场景承担信息。
- 用旁白总结主题，却没有人物行动、物件变化或后续风险。
- 让关键角色变成旁观者，只为展示某个强能力或设定。
- 为了节奏删掉必要因果，导致下一章压力来源不清。
- 把灵感片段、旧稿或 worker 临时设想直接提升为正式事实。
