# 维护与迁移

用于改名、称呼统一、设定同步和结构维护。

## 改名流程

1. 确认旧名和新名是否已定。
2. 写入 `references/name-map.md`。
3. 用 `rg` 搜索旧名和相近写法。
4. 只替换本轮确认范围，不扩散到旧稿存档。
5. 运行：

```bash
python scripts/check-names.py --work <work-id>
```

## 设定同步流程

1. 找正式事实源：角色卡、专项设定、分幕大纲、总纲。
2. 判断冲突来源。
3. 先改最高优先级文件，再决定是否同步正文、大纲或说明。
4. 不把灵感片段直接提升为正式设定。

## public 仓库边界

不要提交：

- 第三方作品全文、抓取语料、批量原文节选。
- token、`.env`、账号信息。
- 临时脚本、缓存、zip、raw/原文目录。
