# Fiction Editing Workflow

适用于正文润色、重写、续写和局部改稿。写作协作规范以 `.agents/skills/novel-fiction/SKILL.md` 为准。

## Steps

1. 确认目标作品，默认 `works/song-of-blaze/`。
2. 读取作品 `README.md`、`ka.yaml`、`state/README.md`。
3. 按任务读取相关 `drafts/`、`plan/`、`canon/` 和 `style/`。
4. 用户要求直接改时，最小范围编辑；用户要求先看时，只给审读和方案。
5. 改后按 skill 自验规则回读上下文。
