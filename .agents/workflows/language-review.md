# Language Review Workflow

适用于中文小说语言的翻译腔检查、生造词梳理和自然度审核。

## 何时使用

- 新写完一章后做语言自查
- 审读他人或旧稿时发现语言不自然
- 用户反馈"读起来像翻译的"
- 定期批量扫描整部作品的语言质量

## 执行方式

**语言质量判断依赖大模型的语感逐段审读，不依赖正则脚本。**

逐章通读正文，从以下维度逐段判断：

## 审读清单

### 1. 翻译腔与生造词

- 是否有"在此过程中""在某种意义上""从……角度来看"等英文前置词句式？
- 是否有"被……所……"连续被动？
- 是否有日轻残留句式（"X什么的"过度、"X地"副词滥用）？
- 是否有生造词或学术术语混入奇幻语境（如"熵""权限""具象化""触发器"）？
- 改法参考：删除填充词、被动改主动、抽象词换具体描述。

### 2. 比喻边界

- 所有比喻必须在 POV 人物的生活经验范围内。
- 露维的世界没有铁、火（遇天泽前）、书、城市、地平线、大海。
- 问：露维在哪里见过这个喻体？答不上来就换。

### 3. 对话自然度

- 每个角色的说话方式与角色卡一致吗？
- 有没有角色突然变成作者的传声筒讲设定？
- 对话是否嵌在动作/体感中，而非孤立成段？

### 4. 体感优先级

- 露维是触觉/温度 > 嗅觉 > 听觉 > 视觉。
- 环境描写是否从体感开始而非视觉开始？

### 5. 排比与抒情

- 禁止"想X，想Y，想Z"三连排比。
- 禁止"X得Y，X得Z"堆叠。
- 情绪标签（"她很害怕"）替换为体感（"后脖子的汗毛竖了起来"）。

### 6. 词语语感

- 语法正确但耳朵觉得别扭的词（如"缩回"带贬义、"顿"作放置义生僻）。
- 音节重复刺耳的组合（如"带片刮片"）。
- 修饰关系错位（如"光歪歪斜斜地亮着"——歪的是瓶子不是光）。

### 7. 词汇统一

- 专有名词拼写一致，同一事物不出现多个称呼。
- 计量单位统一（步/息/暗季等）。
- 可辅助运行 `python scripts/check-names.py --work song-of-blaze`。

## 常见翻译腔速查

| 翻译腔 | 中文替代 |
|--------|---------|
| 在此过程中 | 删掉，或换成具体动作 |
| 在……的同时 | 拆成两句 |
| 随着……的到来 | 删掉，从事件本身开始 |
| 从……的角度来看 | 删掉，让 POV 自然呈现 |
| 在某种意义上 | 删掉 |
| 被……所…… | 改为主动句，或仅用"被" |
| 受到了……的…… | 改为主动句 |
| ……的具象化 | 换具体描述 |
| 非常/极其/十分 + 地 | 换具体的词 |

## 与文风规范的关系

- 文风规范（`写作资料/文风参考/炽炎的颂歌_文风规范.md`）= 写成什么样
- 本 workflow = 怎么逐段审读语言

写完一章后：通读 → 按清单逐段审读 → 输出问题表和修改建议。

## 问题分级

| 严重度 | 类型 | 处理 |
|--------|------|------|
| 🔴 阻塞 | 正文翻译腔影响阅读流畅度 | 必须改 |
| 🟡 警告 | 设定文档术语不自然但可作内部参考 | 建议改 |
| 🟢 建议 | 风格偏好，语法正确 | 作者判断 |

## 仓库位置

- 名称检查：`python scripts/check-names.py --work song-of-blaze`
