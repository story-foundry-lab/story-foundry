# Illustration Workflow

适用于插画生成、配图和图片插入 Markdown。

## Steps

1. 读取 `.agents/skills/novel-fiction/references/illustration-generation.md`。
2. 读取目标作品 `README.md`、`ka.yaml`、`agent_surface.state` 指向的状态文件。
3. 读取场景相关正文、设定和现有视觉资产 README。
4. 不把生成图当作正式设定来源；需要沉淀设定时另行更新 `故事设定/`。
5. 图片资产放入对应作品资产目录，并在 Markdown 中使用相对作品路径说明来源。
