# Fiction KA Protocol

Fiction KA 是作品级知识资产。完整 KA 推荐包含正文、设定、大纲、章节组细纲、创作进度、资料库、互动试演、文风、灵感、验收、审读、旧稿和 agent 工作面。

## Creative Layers

1. 创作灵感：松散素材，不直接成为事实源。
2. 长期大纲：全书结构、分幕和阶段目标。
3. 章节组细纲：接下来一组章节的短期执行方案。
4. 正文草稿/定稿：单章叙事文本和接手说明。
5. 创作进度：已发生事件、最近章节摘要和下一章承接提示。
6. 结构化资料库：角色、地点、势力、规则、物品等事实卡或索引。
7. 互动试演：分支推演和角色反应实验，默认不进入正史。

## Source Priority

默认优先级：

1. 用户本轮明确指令
2. 角色卡
3. 聚落/专项设定
4. 已定稿正文
5. 当前章节组细纲
6. 分幕大纲
7. 总纲
8. 创作进度
9. 写作资料/灵感片段

冲突时先指出冲突，再给保守修法。不要用 `项目管理/当前状态/`、`项目管理/待办任务/` 或 `项目管理/交接记录/` 替代设定来源。

章节组细纲和创作进度也不能覆盖正式设定。它们只负责把已确认设定和已写正文转成短期执行上下文。
