# Shared Assets

`shared/` 保存跨作品共享的系列资产。这里的内容不是某个单一作品的临时设定，而是多个作品需要保持一致的角色、术语或世界观基础。

## 使用原则

- 共享资产优先于单个作品内的临时写法。
- 单个作品可以补充该作品阶段的表现、关系和限制，但不要复制一份再改成另一个版本。
- 如果共享资产和作品内正文/设定冲突，先指出冲突，再决定是更新共享资产，还是修正作品内表现。
- public 仓库仍遵守 public hygiene：不放 token、私有账号信息、第三方作品全文、抓取语料或批量原文节选。
